# JAH Automotive one-page website

Static HTML hosted by GitHub Pages. Open `index.html` locally to review. Edit `styles.css` for styling; the palette variables are at the top of that file.

## Before public launch

1. Ask Lashawn to approve the business copy, address, phone, hours, and use of his first name.
2. The service form prepares an SMS to the published business phone number. A visitor must press Send in their messaging app. Confirm with Lashawn that this number accepts texts. Calls work separately. If it does not accept texts, replace the form action with a Google Form owned by Lashawn before publication.
3. To use Google Forms, create a form with fields for name, phone, vehicle, location, and issue. Link the public responder URL from the service request area and test a submission and response notification. The static site cannot create his form or receive submissions itself.
4. Confirm that the quoted customer review may be featured on the site.

## Publish on GitHub Pages

This repository is configured to deploy `main` from the root. Keep `index.html` and `styles.css` together. No server, build step, or package installation is needed.
