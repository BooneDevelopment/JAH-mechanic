# JAH Automotive one-page website

Static HTML suitable for GitHub Pages. Open `index.html` locally to review.

## Before public launch

1. Ask Lashawn to approve the business copy, address, phone, hours, and use of his first name.
2. The service form prepares an SMS to the public listing phone number. A visitor must press Send in their messaging app. Confirm with Lashawn that this number accepts texts. Calls work separately. If it does not accept texts, replace the form action with a Google Form owned by Lashawn before publication.
3. To use Google Forms, create a form with fields for name, phone, vehicle, location, and issue. Link the public responder URL from the service request area and test a submission and response notification. The static site cannot create his form or receive submissions itself.
4. Review the live Google listing and update the rating if needed. The site links to live reviews and does not freeze a review count.

## Publish on GitHub Pages

Create a repository, upload `index.html` and this README to its root, then select **Settings → Pages → Deploy from a branch → main / (root)**. Visit the Pages URL once GitHub finishes deploying. No server, build step, or package installation is needed.
